## Що є в меню

- **Роботи** — портфоліо. Усі роботи + окремий список схованих.
- **Блог** — статті. Усі статті + окремий список схованих.
- **Команда** — один список людей на весь сайт: сторінка «Про нас», виконавці на роботах, автори статей.

## Робота (сторінка портфоліо)

Поля розкидані по чотирьох вкладках угорі, щоб не гортати одну довгу форму.

### Головне

| Поле | Що це |
|---|---|
| Заголовок | Великий заголовок сторінки: «Сад на схилі в Личакові» |
| Підзаголовок | Рядок під ним: «Дві тераси, рулонний газон і вечірнє світло» |
| Адреса сторінки | Кнопка **Generate** зробить із заголовка `sad-na-skhyli-v-lychakovi`. Кирилиця перекладається в латиницю автоматично |
| Короткий опис | Одне-два речення. Йде на картку в портфоліо і в пошукову видачу |
| Обкладинка | Головне фото: банер сторінки та картка |

### Факти про об'єкт

Локація, площа, дата початку й завершення, скільки тривало, види робіт (прив'язані до
розділів послуг — на сайті стають клікабельними), теги, інструменти й техніка,
матеріали та рослини з кількістю, хто з команди працював.

У блоці «Хто працював» обираєте людину зі списку команди. Поле «Роль саме на цьому
об'єкті» — необов'язкове: якщо порожнє, візьмемо посаду з картки співробітника.

Тривалість можна не заповнювати, якщо є дати — але поки що сайт не рахує її сам,
тож для красивого «5 тижнів» це поле краще заповнити.

### Наповнення сторінки

Тут збираєте сторінку з блоків у будь-якому порядку. Натискаєте **Add item** і обираєте тип:

| Блок | Для чого |
|---|---|
| **Текст** | Заголовок, підзаголовок і текст. У тексті доступні підзаголовки, списки, жирний, курсив, цитата |
| **Слайдер фото** | Кілька фото, які на сайті гортаються стрілками, крапками або пальцем |
| **До / після** | Два кадри з однієї точки. Підписи до кожного кадру свої — «Травень 2024» / «Вересень 2024» |
| **Відео** | Скільки завгодно роликів. Кожен — або посилання на YouTube/Vimeo, або завантажений файл |
| **Список із галочками** | Склад робіт, що входить у послугу, чеклист |
| **Цитата / відгук** | Слова клієнта великим шрифтом |
| **Цифри** | Кілька великих чисел із підписами: «320 м² рулонного газону» |
| **Фото на всю ширину** | Один широкий кадр-акцент |

Блоки можна перетягувати мишею, щоб змінити порядок. Тло секцій на сайті чергується
автоматично — думати про це не треба.

### Налаштування та SEO

- **Порядок** — менше число, вище в портфоліо.
- **Показувати на головній** — вимкніть, щоб робота лишилась доступною за прямим посиланням, але зникла зі списку.
- **Сховати з сайту** — робота зникає повністю.
- **SEO** — заповнюйте, лише якщо текст для пошуковика має відрізнятися від того, що на сторінці. Порожні поля беруться з основного контенту.

## Стаття (блог)

Той самий конструктор блоків, що й у роботах. Відрізняються лише поля на вкладці
«Автор і рубрика»:

- **Автор** — зі списку команди. Внизу статті з'явиться його фото та опис із картки.
- **Дата публікації** — за нею сортується блог.
- **Рубрика** — показується над заголовком.
- **Теги** — вільні, пишете свої.
- **Час читання** — у хвилинах. Сайт поки не рахує сам, тож впишіть приблизно (≈200 слів на хвилину).
- **Згадані роботи** — внизу статті з'являться картки цих робіт.

## Що варто пам'ятати

**Обов'язково натискайте Publish.** Чернетки через публічний API не віддаються — сайт їх
не побачить.

**Опис для SEO у фото** — не пропускайте. Це те, що читають пошуковики та програми для
незрячих. Studio підсвітить попередження, якщо поле порожнє.

**Відео краще посиланням.** Завантажені файли їдять безкоштовну квоту трафіку Sanity дуже
швидко і не підлаштовують якість під швидкість інтернету глядача. Файли лишайте для
коротких роликів, які не хочете публікувати на YouTube.

**Фото не треба різати заздалегідь.** Заливайте великий оригінал — розміри під кожне місце
на сайті Sanity зробить сам. У налаштуваннях фото є «hotspot»: вкажіть центр кадру, і при
обрізанні під різні пропорції головне не відріжеться.
