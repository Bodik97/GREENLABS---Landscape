# Приймач заявок

Маленька функція на Cloudflare Workers: приймає заявку з форми сайту й
пересилає її в Telegram-групу та в Google Таблицю.

Потрібна тому, що сайт статичний — усе, що є в його коді, публічне. Токен бота
там тримати не можна: будь-хто відкриє бандл і зможе слати повідомлення від
імені вашого бота. Тут токен лежить у секретах Cloudflare.

## Що робить

- перевіряє ім'я й телефон, відсіює порожні та явно несправжні
- ловить ботів на приховане поле-пастку: відповідає «прийнято», але нікуди не шле
- обмежує кількість заявок з однієї адреси (5 на годину), якщо підключено KV
- приймає запити лише з дозволених доменів
- екранує текст, щоб через ім'я не можна було підсунути розмітку в Telegram
- шле заявку в Telegram і в таблицю одночасно; якщо один канал недоступний,
  заявка все одно осідає в другому
- **не** відповідає успіхом, якщо заявку не прийняв жоден канал — тоді сайт
  чесно покаже помилку з телефоном замість «дякуємо»

## Розгортання

### 1. Бот

Створює **власник бізнесу зі свого акаунта** — Telegram не дозволяє передавати
ботів між акаунтами, тож бот назавжди лишиться в того, хто його зареєстрував.

1. Написати `@BotFather`, команда `/newbot`
2. Задати назву й нік бота
3. Зберегти отриманий токен

### 2. Група

1. Створити групу, додати менеджера
2. Додати туди бота як учасника
3. Дізнатися ID групи: написати в групу будь-що і відкрити
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — потрібне значення
   `message.chat.id`, воно від'ємне і починається з `-100`

Якщо групу створювали не з акаунта власника — передайте йому права власника
через налаштування групи. Для груп Telegram це підтримує.

### 3. Таблиця

1. Створити Google Таблицю (шапку робити не треба — перша заявка створить її сама)
2. У ній: **Розширення → Apps Script**
3. Стерти те, що в редакторі, і вставити вміст файлу `worker/sheet.gs`
4. Зберегти (дискета), назвати проєкт як завгодно
5. **Розгорнути → Новий розгортання → тип «Веб-застосунок»**, параметри:
   - *Виконувати від імені*: **Я**
   - *Хто має доступ*: **Усі**
6. Google попросить дозвіл — погодитись (на екрані «Google не перевірив цей
   застосунок» тиснути *Додатково → Перейти до …*, це ваш власний скрипт)
7. Скопіювати адресу вигляду
   `https://script.google.com/macros/s/AKfy…/exec`

Ця адреса — фактично ключ до таблиці: хто її знає, той може дописувати рядки.
Тому вона лежить у секретах Cloudflare, а не в коді сайту. Якщо колись
«витече» — зробіть у Apps Script нове розгортання, стара адреса перестане
працювати.

Доступ до самих заявок дається звичайним «Поділитися» на таблиці.

### 4. Worker

```bash
cd worker
npx wrangler login
npx wrangler secret put BOT_TOKEN   # вставити токен з BotFather
npx wrangler secret put CHAT_ID     # вставити ID групи
npx wrangler secret put SHEET_URL   # вставити адресу з кроку 3
npx wrangler deploy
```

Таблиця необовʼязкова: без `SHEET_URL` Worker працює як раніше, тільки Telegram.

Worker уже розгорнутий за адресою
`https://greenlabs-leads.myshop-api.workers.dev`. Сховище для обмеження частоти
теж створене й підключене в `wrangler.toml`, окремих дій не потребує.

Лишається тільки покласти три секрети командами вище і повторити `deploy` —
без них Worker відповідає `502 delivery_failed`, бо заявку нікуди подіти.

### 5. Підключення сайту

У Vercel: проєкт `greenlabs` → **Settings → Environment Variables**

```
Name:  VITE_LEAD_ENDPOINT
Value: https://greenlabs-leads.myshop-api.workers.dev
```

Далі будь-який пуш у `main` пересоберe сайт уже з підключеною формою. Змінну
читає збірка, а не браузер, тож без нового викочування вона не застосується.

Поки змінна порожня, форма не вдає, ніби заявку прийнято, — вона показує
помилку з номером телефону.

### 6. При зміні домену сайту

Дописати новий домен першим у `ALLOWED_ORIGINS` у `wrangler.toml` і виконати
`npx wrangler deploy`. Інакше браузер заблокує надсилання з нового домену.

## Перевірка

```bash
curl -X POST https://greenlabs-leads.myshop-api.workers.dev \
  -H "Content-Type: application/json" \
  -H "Origin: https://greenlabs-one.vercel.app" \
  -d '{"name":"Тест","phone":"+380671234567"}'
```

Очікувано: `{"ok":true}`, повідомлення в групі й новий рядок у таблиці.

Якщо `{"ok":true}` прийшов, а рядка в таблиці немає — дивіться, що каже Worker:

```bash
npx wrangler tail
```

Рядок `sheet 401` або `sheet 403` майже завжди означає, що при розгортанні
скрипта вибрано не «Усі» в полі «Хто має доступ».
